# Concierge AI: Global Settings

The **Global Settings** section allows administrators to configure the core behavior and policies of the Concierge AI across the entire system.

## Key Features

### 1. Model Configuration
- **Purpose**: To select and configure the underlying AI models used by the Concierge.
- **Functionality**: An interface to choose different AI models for different tasks (e.g., a fast model for chat, a powerful model for analysis). Administrators can also adjust parameters like `temperature` to control the creativity of the AI's responses.

### 2. Safety Filters
- **Purpose**: To ensure that AI-generated content is appropriate and safe.
- **Functionality**: Provides settings to configure content safety filters, blocking harmful or inappropriate responses based on various categories (e.g., hate speech, harassment).

### 3. Data Retention
- **Purpose**: To manage how long conversation data with the AI is stored.
- **Functionality**: Allows administrators to set data retention policies to comply with privacy regulations and manage storage costs. For example, setting a policy to automatically delete all conversations after 90 days.
