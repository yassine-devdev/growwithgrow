# Concierge AI: Usage Analytics

The **Usage Analytics** section provides detailed insights into how the Concierge AI is being used across the platform, helping administrators monitor activity and manage costs.

## Key Features

### 1. Overall Usage
- **Purpose**: To provide a high-level overview of all AI activity.
- **Functionality**: A dashboard featuring AI-generated charts that visualize key metrics like the total number of API calls over time, most active users, and peak usage hours.

### 2. By School
- **Purpose**: To break down AI usage metrics on a per-school basis.
- **Functionality**: A detailed view that allows administrators to filter usage data for specific schools. This is essential for understanding how different clients are utilizing the AI and for client-specific reporting.

### 3. Cost Analysis
- **Purpose**: To track the costs associated with AI model usage.
- **Functionality**: A financial dashboard that provides an analysis of API costs, showing spending trends over time and breaking down costs by model or by school. This helps in managing the budget for AI services.
