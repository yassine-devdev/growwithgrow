# Concierge AI: System Prompts

The **System Prompts** section allows administrators to define the core behavior, personality, and instructions for the Concierge AI. A system prompt is a set of instructions given to the AI to guide its responses.

## Key Features

### 1. Prompt Library
- **Purpose**: A central repository for all saved system prompts.
- **Functionality**: Users can browse, search, and manage a library of pre-defined system prompts. This allows for quick switching between different AI personas or behaviors (e.g., "Helpful Assistant," "Socratic Tutor," "Code Debugger").

### 2. Create New Prompt
- **Purpose**: To create custom system prompts for specialized tasks.
- **Functionality**: An editor where administrators can write and test new system prompts. This allows for fine-tuning the AI's role, tone, and response format to fit specific needs.

### 3. Performance
- **Purpose**: To analyze the effectiveness of different system prompts.
- **Functionality**: Provides analytics on how different prompts perform, including metrics like user satisfaction ratings and task completion rates. This data helps in optimizing prompts for better performance.
