# Concierge AI: Schools

The **Schools** section is dedicated to managing how the Concierge AI is deployed and used by different educational institutions on the platform.

## Key Features

### 1. Manage Schools
- **Purpose**: To control which schools have access to the Concierge AI features.
- **Functionality**: A dashboard where administrators can enable or disable AI functionalities on a per-school basis and configure school-specific settings.

### 2. Onboarding
- **Purpose**: To streamline the process of introducing and setting up the AI for new school clients.
- **Functionality**: Provides tools and checklists for the AI onboarding process, including setting up initial system prompts and user permissions for a new school.

### 3. Analytics
- **Purpose**: To track AI usage and performance for each school.
- **Functionality**: A detailed analytics view that breaks down AI usage metrics by school. This helps in understanding how different institutions are leveraging the AI and provides data for billing and support.
