# Concierge AI: Chat Hub

The **Chat** section has been expanded into a comprehensive AI hub with three distinct modes, accessible via a dedicated L3 sidebar. This transforms the Concierge from a simple chatbot into a multi-faceted assistant.

## Key Modes

### 1. Chat (General Assistant)
- **Purpose**: A conversational AI for general questions and assistance.
- **Functionality**: This is the main chat interface, featuring:
  - **Voice-to-Text**: Users can click the microphone icon to speak their queries, which are transcribed in real-time.
  - **Text-to-Speech**: An option to have the AI's responses read aloud for a hands-free experience.

### 2. Report (Dashboard Report Generator)
- **Purpose**: To generate high-level reports by querying data from across the entire application.
- **Functionality**: Users can make natural language requests (e.g., "Summarize Q3 deals and top marketing campaigns"), and the AI will generate a detailed report by pulling and synthesizing the relevant data.

### 3. Automation (Developer Assistant)
- **Purpose**: An AI-powered assistant specifically for technical and development tasks.
- **Functionality**: This mode is primed to help with coding questions, debugging, writing scripts, and providing architectural advice. It formats code snippets correctly within the chat interface, making it a powerful tool for developers managing the system.
