
# Layout: Level-2 Sidebars

For modules that are particularly complex or function like self-contained applications, a Level-2 (L2) vertical sidebar is used instead of the header-based tab navigation. This pattern provides more space for navigation items and is better suited for tool-heavy interfaces.

## Usage

This pattern is prominently used in sections like:
-   **Dashboard**: To switch between Overview, Analytics, and Reports.
-   **School Hub Sub-sections**: Each user type (Student, Parent, Teacher) has its own dedicated L2 sidebar with a long list of specific features.
-   **CRM Sub-sections**: Sections like "Dashboard" or "Contacts" within the CRM have their own L3 sidebars, which follow the same design principle.
-   **AI Tools**: To switch between the Text, Chart, and Image generators.

## Functionality

-   **Contextual Navigation**: The sidebar content is specific to the active L2 or L3 section.
-   **Iconography**: Each navigation item uses a clear icon and a concise label to quickly communicate its purpose.
-   **Active State**: The currently selected item is visually highlighted.
-   **Grouping**: In some cases, sidebars are divided into logical groups (e.g., "Core" vs. "Innovation" tools) to improve organization.

## Design

-   **Position**: Always docked to the left of the main content area for the specific module.
-   **Style**: Housed within its own container, often with a color scheme that matches its parent module to reinforce context (e.g., the School Hub sidebars have different colors for each user type).
