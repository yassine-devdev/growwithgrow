
# Layout: Right Sidebar

The Right Sidebar serves as the primary, Level-1 (L1) navigation for the application. It provides quick access to the main, high-level modules of the system.

## Functionality

-   **Module Switching**: Clicking an icon in the sidebar instantly switches the entire main content area to the corresponding module.
-   **Active State**: The currently active module is visually highlighted with a neon glow and an accent bar, consistent with the cyberpunk aesthetic.
-   **Icons & Labels**: Each button features a unique icon and a concise text label to clearly identify the module.
-   **Hover Effects**: Provides clear visual feedback when a user hovers over a module button.

## Design

-   **Position**: Permanently docked to the right side of the screen for consistent access.
-   **Style**: Housed within a `GlassCard` component to maintain the application's glass morphism theme.
-   **Modules Included**: This sidebar is reserved for the core, business-oriented modules such as Dashboard, Tools, School Hub, CRM, etc. Personal and leisure-focused modules are accessed via the Bottom Dock.
