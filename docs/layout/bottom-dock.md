
# Layout: Bottom Dock

The Bottom Dock is a taskbar-like component located at the bottom of the screen. Its primary function is to serve as a launcher for the "personal" modules, which open as full-screen overlays.

## Key Features

1.  **App Launcher Toggle**:
    -   A primary "app drawer" icon on the left of the dock.
    -   Clicking this icon toggles the visibility of the personal module launcher bar.

2.  **Personal Modules Bar**:
    -   When toggled, a horizontal, scrollable list of personal modules appears.
    -   This bar contains icons for modules like Leisure & Lifestyle, Hobbies, Media, Studio, and Marketplace.

3.  **Launching Overlays**:
    -   Clicking any module icon in the bar launches that module as a **Full-Screen Overlay**.
    -   After launching an app, the launcher bar typically hides to provide a clean workspace.

## Window Management Analogy

The Bottom Dock and Full-Screen Overlay system mimic a modern desktop operating system's window management:
-   **Bottom Dock**: Acts like a taskbar or dock for launching applications.
-   **Full-Screen Overlays**: Act like maximized applications running on top of the main workspace.
-   **Reduce/Minimize**: The "reduce" button in an overlay's header minimizes the app, hiding the overlay but showing the launcher bar again, similar to minimizing a window to the taskbar.
