# Communications Module: Announcements

The **Announcements** section is a tool for administrators and authorized users to create and broadcast important messages to all users of the system or to specific groups.

## Key Features

### 1. All Announcements
- The main view that displays a chronological feed of all published announcements.
- Users can quickly catch up on the latest news, system updates, and important information.

### 2. Drafts
- A private workspace for creating and saving announcements before they are published.
- This allows for collaborative writing and review before a message goes live.

### 3. Published
- A view that shows only the announcements that are currently live and visible to users.
- This section provides tools for administrators to edit, archive, or retract published announcements.
