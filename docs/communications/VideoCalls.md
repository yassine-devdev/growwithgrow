# Communications Module: Video Calls

The **Video Calls** section provides integrated video conferencing capabilities, allowing users to start, schedule, and review video meetings directly within the application.

## Key Features

### 1. Start & Schedule Calls
- The L3 sidebar includes prominent actions to immediately start a new video call or schedule one for a future date and time.
- Scheduled calls are automatically added to the user's calendar.

### 2. History
- Provides a log of all past video calls.
- Users can view details such as participants, duration, and date for each call.

### 3. Recordings
- A repository for all cloud-recorded video meetings.
- Users with the appropriate permissions can view, download, or share recordings of past calls.
