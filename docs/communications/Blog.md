# Communications Module: Blog

The **Blog** section is a content management system (CMS) integrated directly into the Communications module. It allows authorized users to write, publish, and manage articles, as well as track their performance.

## Layout
The Blog features a two-panel layout:
- **L3 Sidebar**: A vertical navigation bar on the left provides access to the main functional areas of the blog.
- **Main Content Area**: Displays the selected view, such as the post list, category manager, analytics dashboard, or the post editor.

## Key Features

### 1. All Posts
- The default view, showing a filterable and searchable list of all blog posts.
- Users can see the status (Published, Draft), author, and date of each post. From here, they can choose to edit existing posts or create a new one.

### 2. Categories
- An interface for managing the categories used to organize blog posts.
- Users can create, rename, and delete categories to maintain a well-structured blog.

### 3. Analytics
- A dashboard that provides insights into blog performance.
- Features AI-generated charts to visualize key metrics like:
  - Post Views Over Time
  - Top Posts by Engagement
  - Traffic Sources

### 4. Post Editor
- A dedicated view for writing and editing blog posts.
- Provides a clean writing interface alongside panels for managing post settings, such as assigning categories, setting a featured image, and scheduling publication.
