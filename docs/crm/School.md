# CRM Module: School

The **School** section is a specialized view within the CRM designed specifically for managing relationships with educational institutions. It provides a dedicated suite of tools for the entire school lifecycle, from onboarding to billing and analytics.

## Key Features

### 1. All Schools
- **Purpose**: The main dashboard for viewing and managing all school clients.
- **Functionality**: A comprehensive table view listing all schools, their primary administrator, current status (Active, Trial, Inactive), student count, and subscription plan.

### 2. Add School
- **Purpose**: To onboard a new educational institution onto the platform.
- **Functionality**: A dedicated action that opens a modal for entering all necessary information for a new school client.

### 3. Data Import
- **Purpose**: To facilitate the bulk upload of school-related data.
- **Functionality**: A tool for importing data such as student rosters or staff lists from CSV or XLSX files, streamlining the setup process for new schools.

### 4. Preferences
- **Purpose**: To configure global settings related to school management.
- **Functionality**: Allows administrators to set default notification preferences, define the academic year start, and other system-wide settings that affect all school clients.

### 5. Billing & Subscriptions
- **Purpose**: To manage the subscription plans and billing history for schools.
- **Functionality**: A dashboard to view and compare different subscription tiers, see a school's current plan, and access their billing history.

### 6. Analytics
- **Purpose**: To provide high-level insights into the school client base.
- **Functionality**: An analytics dashboard displaying key metrics like total number of schools, active subscriptions, total student count across all schools, and Monthly Recurring Revenue (MRR).
