# CRM Module: Settings

The **Settings** section allows administrators to customize and configure the CRM module to fit their specific business processes.

## Key Features

### 1. Pipeline
- **Purpose**: To customize the stages of the sales pipeline.
- **Functionality**: An interface where users can add, remove, rename, and reorder the stages that appear in the "Deals" pipeline view. This ensures the CRM aligns with the company's unique sales process.

### 2. Properties
- **Purpose**: To create and manage custom data fields for CRM records.
- **Functionality**: Allows administrators to create custom properties for contacts, companies, and deals (e.g., a "Lead Score" number property for contacts, or an "Industry" dropdown for companies). This enables the CRM to store all relevant business data.

### 3. Team
- **Purpose**: To manage user access and roles within the CRM.
- **Functionality**: An interface to add or remove team members from the CRM module and assign them roles (e.g., Sales Rep, Manager, Admin) that determine their permissions and visibility.
