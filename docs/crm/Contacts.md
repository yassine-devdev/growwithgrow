# CRM Module: Contacts

The **Contacts** section is the core database for managing all individuals and organizations within the CRM.

## Key Features

### 1. All Contacts
- **Purpose**: The primary view for all individual contacts.
- **Functionality**: A searchable and filterable table displaying all contacts with key information like email, company, phone number, and lead status. Users can add new contacts and open a detail view for more information.

### 2. Companies
- **Purpose**: To manage records of organizations.
- **Functionality**: A dedicated view for company profiles. Each company record can be linked to multiple contacts, providing a holistic view of an organization's relationship with the business.

### 3. Lists
- **Purpose**: To segment contacts for targeted marketing and communication.
- **Functionality**: Users can create static or dynamic lists based on specific criteria (e.g., "Newsletter Subscribers," "High-Value Leads"). These lists can then be used in other modules for email campaigns or targeted outreach.

### 4. Import/Export
- **Purpose**: To facilitate bulk management of contact data.
- **Functionality**: Provides tools to import contacts from a CSV file and export existing contact data for use in other systems.
