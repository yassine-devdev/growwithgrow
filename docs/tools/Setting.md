# Tools Module: Setting

The **Setting** section allows users to configure preferences and manage settings specifically for the Tools module.

## Key Features

### 1. API Keys
- **Purpose**: To manage API keys for any third-party services that integrate with the Tools module.
- **Functionality**: An interface to add, view, and revoke API keys for connected services.

### 2. Usage Limits
- **Purpose**: To monitor and set limits on the usage of resource-intensive tools, such as AI generators.
- **Functionality**: Displays current usage statistics against monthly or daily quotas and allows administrators to set usage limits for different user roles.

### 3. Defaults
- **Purpose**: To configure default settings and preferences for various tools.
- **Functionality**: Users can set default chart colors, preferred text generation tones, or default image aspect ratios to streamline their workflow.
