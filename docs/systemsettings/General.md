# System Settings: General

The **General** settings section allows users to configure their personal profile, customize the application's appearance, set localization preferences, and manage AI provider configurations.

## Key Features

### 1. Profile
- **Purpose**: To manage basic user account information.
- **Functionality**: Users can view and edit their full name and the email address associated with their account.

### 2. Appearance
- **Purpose**: To customize the visual theme and layout of the user interface.
- **Functionality**: Includes options to switch between different UI themes (e.g., Cyberpunk Dark, Solarized Light) and adjust the overall scale of UI elements for better accessibility and comfort.

### 3. Localization
- **Purpose**: To adapt the application to the user's language and region.
- **Functionality**: Users can select their preferred language for the UI and set their local timezone, which ensures that all dates and times are displayed correctly.

### 4. AI
- **Purpose**: To configure the backend AI services used throughout the application.
- **Functionality**: Allows selection and configuration of different AI providers, such as a local Ollama instance, OpenRouter, or OpenAI, for various generative AI features. This provides flexibility and control over AI service usage.
