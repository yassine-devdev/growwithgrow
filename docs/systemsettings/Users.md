# System Settings: Users

The **Users** section is where administrators manage user accounts, define access levels through roles, and handle invitations.

## Key Features

### 1. All Users
- **Purpose**: To provide a comprehensive view of all user accounts in the system.
- **Functionality**: A searchable list of all users, displaying their name, email, assigned role, and status (e.g., Active, Invited). Administrators can edit user details or remove accounts from this view.

### 2. Roles & Permissions
- **Purpose**: To create and manage user roles with granular permissions.
- **Functionality**: An interface for defining roles (e.g., Admin, Manager, User, Contributor) and assigning specific permissions to each. This allows for precise control over what different types of users can see and do within the application.

### 3. Invitations
- **Purpose**: To invite new users to the platform and track the status of those invitations.
- **Functionality**: Administrators can send email invitations to new users. This view provides a log of all pending and accepted invitations, with the ability to resend or revoke an invitation.
