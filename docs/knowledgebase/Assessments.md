# Knowledge Base: Assessments

The **Assessments** section provides a comprehensive toolkit for creating, managing, and analyzing student tests and quizzes, featuring both traditional and advanced AI-powered capabilities.

## Core Features

### 1. Create New
- **Purpose**: To build custom assessments from scratch.
- **Functionality**: An intuitive editor for creating tests, adding various question types (multiple choice, short answer, etc.), and setting scoring rules.

### 2. Question Bank
- **Purpose**: A centralized repository for all assessment questions.
- **Functionality**: Allows educators to store, categorize, and reuse questions across multiple assessments, saving time and ensuring consistency.

### 3. View Results
- **Purpose**: To analyze student performance on assessments.
- **Functionality**: A dashboard that provides detailed analytics on test results, including class averages, question-by-question breakdowns, and individual student performance reports.

## Innovation (AI-Powered) Features

### 1. Generative Assessments (AI)
- **Purpose**: To automatically create assessments based on curriculum content.
- **Functionality**: An AI tool that can scan a lesson plan or topic and generate relevant assessment questions, complete with answers and difficulty levels.

### 2. Adaptive Testing Engine
- **Purpose**: To create personalized testing experiences for each student.
- **Functionality**: An advanced engine that adjusts the difficulty of questions in real-time based on a student's answers, providing a more accurate measure of their knowledge level.

### 3. Integrity Shield (AI)
- **Purpose**: To deter and detect academic dishonesty during online assessments.
- **Functionality**: An AI-powered proctoring tool that can flag suspicious behavior, such as switching tabs or using unauthorized resources, during a test.
